# Color-Cal

**측정한 단색 계조를, 작업에 바로 쓸 수 있는 CMYK 보정값으로.**

Color-Cal은 인쇄장비의 C·M·Y·K 단색 출력 특성을 측정하고, 채널별 계조 보정값을 구하는 웹 애플리케이션입니다. ICC 프로파일을 직접 적용하기 어려운 환경에서 측정값을 정리하고 보정 전후 결과를 비교하는 데 사용할 수 있습니다.

작업자가 직접 제작·인쇄한 패치의 CIELab 값을 입력하면 보정 테이블을 생성합니다. 보정 패치를 다시 측정해 결과를 검토하고, 확정한 테이블로 그래픽 작업에 사용할 CMYK 수치를 변환할 수 있습니다.

[**Color-Cal 열기**](https://steves460ng.github.io/color-cal/) · [사용자 매뉴얼](docs/user-guide.md)

## Color-Cal의 장점

### 그래픽 작업에 바로 사용하는 정수 CMYK

정수값 모드를 켜면 제작 가이드, 계산기, 복사 및 CSV 내보내기에 정수 보정값을 제공합니다. 소수 입력을 지원하지 않는 작업 환경에서도 수치를 그대로 옮겨 사용할 수 있습니다. 소수점 정밀도가 필요한 작업은 모드를 끄고 제작 정밀도를 선택하면 됩니다.

화면에 표시하는 제작값과 내부 계산값은 따로 관리하므로, 정수로 반올림해도 계산용 원본 정밀도를 유지합니다.

### 측정부터 검증까지 이어지는 작업 흐름

1차 측정 → 보정값 계산 → 2차 제작·측정 → 결과 비교를 한 프로젝트에서 관리합니다. L*·a*·b\* 그래프와 계조 오차를 함께 보며 보정이 어떤 변화를 만들었는지 확인할 수 있습니다. 2차 측정에는 실제 제작에 사용한 입력값을 기록해 권장값과 실제 작업을 구분합니다.

### 필요한 채널과 측정 간격을 선택

C·M·Y·K 중 필요한 채널만 측정할 수 있습니다. 기본 5% 간격 외에 1%, 2%, 10% 및 사용자 지정 간격을 지원하므로, 작업 시간과 필요한 측정 밀도에 맞춰 구성할 수 있습니다.

### 반복 작업을 위한 프로젝트와 버전 관리

장비, 용지, 잉크, RIP 및 측색 조건을 프로젝트별로 기록합니다. 프로젝트 복제로 조건별 시험을 나누고, 보정 버전별로 원본 측정값과 2차 결과를 보존할 수 있습니다. 확정 버전은 편집을 잠그며, 출력 조건이나 설정이 달라진 이전 버전은 계산기에 적용되지 않도록 안내합니다.

### 브라우저에서 저장하고 파일로 보관

별도 프로그램 설치나 계정 등록 없이 브라우저에서 사용합니다. 측정 입력은 자동 저장되며 마지막 작업 위치를 복원합니다. JSON 백업으로 프로젝트를 보관하거나 다른 브라우저로 옮기고, CSV로 측정값과 보정 결과를 활용할 수 있습니다.

## 준비할 것

- 측정할 인쇄장비, 용지 및 잉크
- CMYK 수치를 지정해 패치를 제작할 그래픽 프로그램
- CIELab 값을 측정할 수 있는 분광측색계
- 웹 브라우저와 일관된 출력·측색 조건

Color-Cal은 **패치 제작에 필요한 수치 목록**을 제공합니다. 작업자는 이 목록으로 패치를 직접 제작·인쇄하고 측정값을 수동 입력합니다.

## 사용 순서

1. **프로젝트 생성** — 장비와 용지, 잉크, 출력 및 측색 조건을 기록합니다.
2. **측정 설정** — 채널, 패치 간격, 정수값 모드를 선택합니다. 기본값은 4채널·5%·정수 ON입니다.
3. **1차 패치 제작** — 가이드의 CMYK 수치를 복사하거나 인쇄해 패치를 제작합니다.
4. **1차 Lab 입력** — 측정값을 입력하고 채널별 완료율과 그래프를 확인합니다.
5. **1차 선형도 리포트** — 보정값을 자동 계산하고 원본 계조의 평균·최대 오차, 검토 구간, 반올림 중복을 확인합니다. 리포트에서 **2차 패치 제작으로 진행**을 누릅니다. 기존 작업은 보존합니다.
6. **2차 제작·측정** — 보정 가이드로 패치를 제작하고 실제 제작 입력값과 Lab를 기록합니다.
7. **결과 검토·확정** — 같은 목표 계조의 1차·2차 결과를 비교하고 사용할 버전을 확정합니다.
8. **계산기 사용·백업** — CMYK를 변환해 복사하고, 결과를 CSV와 JSON으로 보관합니다.

입력 테이블에서는 Tab·Enter로 다음 셀, Shift+Tab·Shift+Enter로 이전 셀로 이동할 수 있습니다.

## 측정 간격과 작업량

각 채널은 다른 세 채널을 0%로 고정해 독립적으로 측정합니다. 모든 간격에서 0%와 100% 패치를 포함합니다.

| 패치 간격 | 채널당 패치 수 | 4채널 패치 수 |
| --------- | -------------: | ------------: |
| 1%        |            101 |           404 |
| 2%        |             51 |           204 |
| 5%        |             21 |            84 |
| 10%       |             11 |            44 |

표의 수량은 한 번의 측정 단계 기준입니다. 1차와 2차를 모두 진행하면 각각의 패치를 제작·측정해야 합니다.

## 보정 계산기

2차 측정을 완료하고 현재 설정에 맞는 보정 테이블을 확정하면 계산기를 사용할 수 있습니다. 입력한 C·M·Y·K를 각각 독립적으로 변환하며, 내부 계산값과 실제 사용할 출력값을 나란히 표시합니다.

- **결과 전체 복사**: `C 38 / M 25 / Y 65 / K 18`
- **CSV 형식 복사**: `38,25,65,18`
- **미보정 채널**: 입력값을 그대로 통과시키고 적용 상태를 표시
- **정수값 모드**: 변환과 복사 결과에 동일한 반올림 규칙 적용

위 수치는 복사 형식을 설명하기 위한 예시이며, 실제 보정값은 프로젝트의 측정 데이터에 따라 달라집니다.

## 데이터 저장과 백업

프로젝트와 측정 데이터는 사용 중인 브라우저의 IndexedDB에 저장됩니다. 자동 저장은 서버 동기화나 영구 백업을 대신하지 않으므로 **중요한 작업 전후에 JSON 백업을 내려받으세요.**

| 파일             | 용도                                                         |
| ---------------- | ------------------------------------------------------------ |
| JSON 백업        | 프로젝트 설정, 측정값, 보정 버전 및 작업 이력 전체 보관·복원 |
| 1차·2차 측정 CSV | 측정 데이터 검토 및 외부 분석                                |
| 보정 테이블 CSV  | 내부 보정값과 제작용 입력값 활용                             |
| 최종 비교 CSV    | 보정 전후 결과 기록 및 공유                                  |

JSON 복원은 별도 프로젝트로 추가되므로 기존 프로젝트를 덮어쓰지 않습니다. 다른 기기나 브라우저에서는 JSON을 복원해 작업을 이어갈 수 있습니다. 사이트 데이터 삭제나 프라이빗 창 종료 시에는 저장한 작업이 사라질 수 있습니다.

## 사용 범위

Color-Cal은 **단색 채널의 계조 선형화**를 지원합니다. 종이색 대비 ΔE76을 정규화한 측정 곡선으로 보정값을 계산하며, 자세한 방법은 [보정 계산 정의](docs/algorithm.md)에서 확인할 수 있습니다.

혼합색의 Lab 예측, ICC 프로파일 생성, 색상 일치 보장, 패치 이미지·PDF 생성 및 측색계 자동 연동은 제공하지 않습니다. 결과의 개선·악화 표시는 상대 비교이며 자동 합격 판정이 아닙니다. 실제 출력 품질과 측정 조건을 검토한 뒤 보정 테이블을 확정하세요.
