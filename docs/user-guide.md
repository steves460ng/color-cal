# 사용자 매뉴얼

사이드바의 **도움말**을 누르면 GitHub의 사용자 매뉴얼이 별도 창으로 열립니다.

## 시작 및 프로젝트 관리

프로젝트 화면에서 **새 프로젝트**를 누르고 이름, 인쇄장비, 용지, 잉크, 해상도, RIP, 측색계, 측색 조건과 메모를 입력합니다. 정보는 자동 저장되며 **정보 저장** 버튼으로도 저장할 수 있습니다. 상단이 아닌 왼쪽의 현재 프로젝트 선택기로 프로젝트를 전환합니다. 복제는 전체 측정·버전을 포함하는 별도 프로젝트를 만듭니다. 삭제는 확인 후 수행되며 되돌리려면 JSON 백업이 필요합니다. 작업 이력은 프로젝트 아래에 표시됩니다.

## 측정 설정

기본값은 C/M/Y/K, 5% 증분, 정수 ON입니다. 채널 하나 이상과 1/2/5/10% 또는 사용자 지정 증분을 선택합니다. 0%와 100%를 항상 포함하며, 7%처럼 나누어떨어지지 않으면 마지막 간격만 짧습니다. 정수 ON은 정수 증분만 허용하고 OFF는 0.1–100% 증분을 허용합니다. 정수 OFF 제작 정밀도는 0–4자리(기본 2)를 선택할 수 있습니다.

설정은 저장 버튼으로 적용합니다. 이미 측정한 데이터는 삭제하지 않습니다. 증분 변경으로 목록에서 사라진 1차 데이터도 JSON 안에 보존합니다. 과거 버전은 생성 당시 설정으로 표시됩니다. 장비·용지·잉크·출력/측색 조건, 모드·채널·증분·정밀도 또는 1차 데이터가 바뀌면 이전 버전을 계산기에 적용할 수 없습니다. 새 버전을 제작·측정·확정해야 합니다.

## 1차 가이드와 입력

채널을 고르고 목록의 CMYK값으로 그래픽 프로그램에서 직접 패치를 만듭니다. 표의 각 행에 제작 채널을 표시하며, 선택 채널의 제작 입력 열을 해당 채널 색상으로 강조합니다. 표에는 선택한 채널의 제작 입력값만 표시합니다. 나머지 채널은 **0% 고정**이며 표 위의 안내에서 확인할 수 있습니다. 제작값 복사에는 CMYK 네 채널의 수치를 모두 포함합니다. 제작 가이드는 Lab 측정 완료 여부를 나타내지 않으며, 측정 내역은 해당 단계의 측정 입력 화면에서 확인합니다. 제작값 복사 또는 현재 채널 가이드 인쇄를 사용합니다. 인쇄물에는 채널·단계 제목과 목표값/제작값 두 열만 표시합니다. 1차는 목표값과 제작값이 같고 2차는 목표 계조에 대응하는 보정 제작값을 표시합니다. 이미지는 생성하지 않습니다. 출력 조건을 고정하고 종이색(0%)부터 최대 농도(100%)까지 측정하세요.

Lab 테이블에서 `L*`는 0–100, `a*`와 `b*`는 유한한 숫자를 입력합니다. 빈칸은 0이 아니며 미입력입니다. 입력 오류는 셀에 표시됩니다. Tab과 Enter는 다음 셀, Shift+Tab과 Shift+Enter는 이전 셀입니다. 값은 입력하면서 자동 저장되고, 채널별 완료율이 갱신됩니다. 마지막 셀과 작업 단계도 복원됩니다. 저장 실패 메시지가 뜨면 창을 닫기 전에 JSON 백업을 받으세요.

## 1차 선형도 진단 리포트

리포트는 채널별 원본 정규화 계조와 이상적인 직선을 비교하고 평균·최대 절대 계조 오차(%p), 계조 역전·평탄·급변·최대 농도 초과 구간, 예상 보정 입력 곡선과 제작값 중복을 보여줍니다. 보정 후 실제 출력 개선을 판정하는 리포트는 아니며, 개선 여부는 2차 측정 결과에서 확인합니다.

검토 구간의 패치 ID를 누르면 해당 채널의 1차 Lab 입력 셀로 돌아갑니다. 이상이 있으면 패치 순서와 측정값을 확인하고 필요한 패치를 재측정하세요. 원본은 단조 회귀로 덮어쓰지 않습니다. 같은 제작값이 겹쳐도 목표 계조별 패치 ID와 측정은 유지합니다.

**리포트 CSV**로 모든 선택 채널의 원본·계조 편차·예상 보정값·검토 항목을 내보내거나 **리포트 인쇄**로 현재 채널의 진단을 인쇄할 수 있습니다. JSON에는 원본과 보정 버전이 보존되므로 다시 열어 리포트를 확인할 수 있습니다. 리포트에 미입력 또는 끝점 오류가 있으면 2차 제작 진행이 비활성화됩니다.

## 계산과 2차 작업

선택한 모든 채널의 1차 입력을 마치면 **1차 선형도 리포트 보기**를 누릅니다. 보정값 계산과 버전 저장을 자동으로 처리하고 원본 계조의 선형도 리포트를 엽니다. 리포트 검토 후 **2차 패치 제작으로 진행**을 누르면 제작 가이드로 이동합니다. 현재 설정·측정값과 맞는 버전이 있으면 재사용하여 기존 2차 입력을 보존합니다. 설정이나 1차 값이 바뀌면 새 버전을 만듭니다. 종이색과 최대 농도색이 같으면 계산을 거부합니다.

테이블 복사·CSV 내보내기, 단일 채널 계산이나 별도 버전 생성이 필요하면 사이드바의 **CMYK 보정 조견표**의 **보정 버전 생성·내부 계산값 (고급)**을 이용합니다. 일반 작업은 이 화면을 거칠 필요가 없습니다.

비단조 곡선 경고가 있으면 패치 순서·장비 상태·측정을 확인하고 필요시 재측정하세요. 보정 방식과 지표는 [계산 정의](algorithm.md)를 참고하세요.

버전 선택기에서 작업할 버전을 선택하고 2차 가이드로 제작합니다. 정수 ON에서는 가장 가까운 정수로 반올림한 제작값을 사용합니다(12.49→12, 12.50→13, 37.53→38, 99.80→100). 중복된 제작값도 목표별 패치 ID와 측정을 유지합니다. 각 패치의 **실제 제작 입력값**과 Lab를 2차 테이블에 기록합니다. 실제 제작값은 권장값과 달라도 기록할 수 있지만, 해당 버전의 정수 규칙과 0–100 범위를 따라야 합니다.

## 비교와 확정

최종 결과에서 같은 목표 계조의 1·2차 Lab, 보정값, 실제 제작값, 계조 오차, ΔE76을 비교합니다. 개선·동등·악화는 상대 비교이며 자동 합격 기준이 아닙니다. 평균은 비교 가능한 패치만 사용합니다. 모든 적용 채널의 실제 입력과 Lab가 유효하고, 실제 제작값이 해당 보정 테이블의 제작값과 일치해야 확정할 수 있습니다. 다른 값으로 측정한 결과도 기록·비교할 수 있지만, 원래 테이블의 검증으로 확정하려면 테이블의 제작값으로 패치를 다시 제작·측정해야 합니다. 현재 원본·설정과 다르면 확정할 수 없습니다. 확정 버전은 수정되지 않습니다. 수정이 필요하면 새 버전을 만들어 다시 측정합니다.

## 계산기

2차 완료, 유효한 현재 버전, 확정을 모두 만족해야 작동합니다. 프로젝트 설정과 다른 과거 버전을 선택하면 이유와 함께 비활성화됩니다. C/M/Y/K 입력을 바꾸면 즉시 변환하며 미보정 채널은 그대로 통과시킵니다. 정수 ON은 정수 입력을 사용합니다. 계산기의 모드 스위치는 이번 변환 출력만 변경하며 프로젝트 설정이나 과거 측정값을 바꾸지 않습니다.

내부값과 제작용 출력값을 따로 표시합니다. **결과 전체 복사**는 `C 38 / M 25 / Y 65 / K 18` 형식, **CSV 형식 복사**는 `38,25,65,18` 형식입니다. 이 예시는 형식 설명이며 실제 값은 측정 데이터에 따라 달라집니다. 클립보드는 HTTPS 또는 브라우저 허용이 필요합니다. 거부되면 CSV 내보내기를 사용하세요.

## 백업과 복원

상단 **JSON 백업**은 현재 프로젝트의 설정·원본·모든 버전·초안·이력 전체를 내려받습니다. **복원**은 앱에서 내려받은 JSON을 별도 프로젝트로 추가하여 이름 뒤에 `(복원)`을 붙입니다. 기존 프로젝트를 덮어쓰지 않습니다. CSV는 1차 입력, 2차 입력, 보정값, 최종 결과 화면에서 각각 내려받습니다. CSV의 제작 열은 정수 ON일 때 정수이고, 내부 열은 원정밀도를 보존합니다. CSV 파일을 측정 입력으로 가져오는 기능은 없습니다.

브라우저나 기기가 바뀌면 JSON으로 이동하세요. IndexedDB는 동기화·영구 백업이 아니며 사이트 데이터 삭제 및 사생활 보호 모드에 주의해야 합니다. 처음 입력할 때와 중요한 작업이 끝날 때마다 백업을 권장합니다.

## 여러 탭과 저장 실패

같은 프로젝트를 여러 탭에서 편집하면 먼저 저장된 변경을 기준으로 충돌을 감지합니다. 오래된 탭의 값으로 최신 측정 데이터를 덮어쓰지 않습니다. 충돌 안내가 뜬 탭에서는 현재 입력을 JSON 백업한 뒤 새로고침하고 필요한 값을 확인해 반영하세요. 측정 입력은 한 탭에서 진행하는 것을 권장합니다.

일시적인 저장 용량 오류가 해결되면 다음 정상 저장 시 자동 저장 상태도 복구됩니다. 브라우저 저장 리비전은 복제·JSON 복원 시 초기화되므로 원본 프로젝트와 별개로 저장됩니다.

## CMYK 보정 조견표와 인쇄

사이드바의 **CMYK 보정 조견표**에서 한 목표값에 대한 C·M·Y·K 제작 입력값을 한 행으로 확인할 수 있습니다. 보정 버전을 선택하고 **조견표 간격**에서 1%, 2%, 5%, 10% 또는 사용자 지정 간격을 고르세요. 사용자 지정은 입력 후 **적용**을 누릅니다. 조견표 간격은 측정 분해능과 독립적이며 측정값과 버전을 변경하지 않습니다. 선택한 간격은 프로젝트에 저장됩니다.

측정점 사이의 값은 계산기와 동일하게 내부 보정값을 선형 보간한 뒤 버전의 정수/소수 규칙으로 반올림합니다. 미보정 채널은 원본값을 그대로 표시하며 헤더와 인쇄물에 미보정임을 표시합니다. 네 채널 값은 각각 독립적인 변환값입니다.

**조견표 인쇄**는 조견표만 여러 단으로 배치해 인쇄합니다. 기본 A4 가로 설정에서 1% 간격의 101개 목표는 세 단으로 배치됩니다. 더 촘촘한 간격은 여러 페이지로 분할합니다. 조견표에는 제목·적용 상태·수치표를 표시하며 프로젝트 설명, 장비·용지·잉크 정보와 보간 설명은 표시하지 않습니다. 실제 페이지 수는 브라우저와 인쇄 배율, 용지 설정에 따라 달라질 수 있습니다. **조견표 CSV**로 같은 제작값과 채널별 적용 상태를 내보낼 수도 있습니다.

확정된 현재 버전은 사용 가능으로 표시합니다. 미확정·불일치 버전은 참고용이며 그 이유를 화면과 인쇄물에 함께 표시합니다. 실제 제작에는 2차 검증과 확정을 마친 현재 버전을 사용하세요. 내부 계산값과 별도 버전 생성은 조견표 아래의 고급 항목을 펼쳐 확인할 수 있습니다.
