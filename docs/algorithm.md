# 보정 계산 정의

계획서 v1.3에는 보정 수학식이 지정되어 있지 않습니다. 이 구현은 다음 경험적 단색 계조 보정 방식을 사용하며 UI에도 방식을 표시합니다. 식별자는 `paper-deltaE76-isotonic-linear-v1`입니다.

## 채널별 보정

측정 입력을 xᵢ, 해당 CIELab를 Pᵢ, 종이색을 P₀, 최대 농도색을 P₁₀₀이라고 합니다.

1. 각 패치의 종이색 대비 색차 dᵢ = √((Lᵢ−L₀)² + (aᵢ−a₀)² + (bᵢ−b₀)²)를 계산합니다.
2. rᵢ = 100 × dᵢ / d₁₀₀으로 정규화합니다. 끝점 색차가 0.01 미만이면 계산을 거부합니다.
3. rᵢ를 [0,100]으로 제한하고 동일 가중치 PAVA 최소제곱 단조 회귀를 적용합니다. 비단조·끝점 초과가 있으면 재측정 권고를 표시합니다. 원본 Lab는 변경하지 않습니다.
4. 목표 계조 t를 정리된 r 곡선에서 역선형 보간하여 내부 입력 x(t)를 구합니다. t=0은 0, t=100은 100입니다. 목표와 일치하는 평탄 구간은 해당 입력 구간의 중점을 선택합니다.
5. 제작값은 정수 ON일 때 Math.round(x), OFF일 때 선택한 소수 정밀도로 반올림합니다. 마지막에 [0,100]으로 제한합니다. 내부 x는 덮어쓰지 않습니다.
6. 계산기는 목표 입력 사이에서 **내부 보정값**을 선형 보간한 뒤, 마지막 출력 단계에서만 반올림합니다.

각 채널에 독립적으로 적용합니다. a*, b*를 포함하는 색차이므로 노랑처럼 L\* 변화만으로는 충분하지 않은 채널도 포함할 수 있습니다. 다만 색상 이동이나 재료·광택·측색 조건의 변화는 단일 계조 함수로 설명할 수 없으므로 작업자가 검토해야 합니다.

## 결과 비교

목표 t에 대한 정규화 계조 오차는 |100 × ΔE76(P₀, P측정) / ΔE76(P₀, P₁₀₀) − t| (%p)입니다. 2차 결과에도 해당 버전의 **1차** 끝점을 사용하여 기준을 유지합니다. 1차와 2차의 같은 목표 t를 비교하고, 오차 차이가 0.01%p 이하이면 동등으로 표시합니다. 실제 제작 입력값이 없거나 유효하지 않으면 비교 완료로 간주하지 않습니다.

별도 ΔE76 열은 P₀ + (P₁₀₀−P₀) × t/100인 Lab 직선 목표와 2차 측정색의 차이를 보여 줍니다. 계조 오차와 ΔE76은 서로 다른 지표입니다. 평균은 비교 가능한 패치 집합에서만 계산합니다. 확정은 자동 합격 판정이 아니라 작업자의 검토·승인입니다.

이 방법은 ISO 농도 선형화, Murray–Davies, Yule–Nielsen 또는 SCTV(ISO 20654)의 구현이 아닙니다. ΔE00, 혼합색 최적화, ICC 생성도 범위 밖입니다. 인쇄 용도에 필요한 표준·측색 조건과 허용 오차는 별도로 결정해야 합니다.

## 수치 보존 및 검증

새 보정 버전은 십진수 자릿수를 이동한 뒤 반올림하여 `1.005 → 1.01`, `2.675 → 2.68`을 처리합니다. 과거 버전은 생성 당시 반올림 방식과 제작값을 그대로 보존합니다. 1차 제작 가이드의 목표 입력과 2차 실제 기록값은 보정 출력 정밀도로 다시 반올림하지 않습니다.

끝점 색차나 정규화 중간값이 유한하지 않으면 보정 버전 생성을 중단합니다. 2차 비교 지표가 계산 범위를 벗어나면 결과를 계산 범위 오류로 표시하고 확정을 차단합니다. 테이블과 실제 제작값이 다른 측정은 비교용으로 보존하지만, 해당 테이블을 검증한 것으로 확정하지 않습니다.
