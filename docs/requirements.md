## 검증

- `tests/core.test.js`: 표준·사용자 증분과 끝점/중복, 반올림 예시, 범위, 유효성, 단조 회귀·역보간, 불완전 입력 거부, 정밀도 보존, 버전 잠재 불일치, 실제 제작값 필수, 확정 활성화, 독립 채널/미보정 통과, 비교 오차, JSON 보존·손상 거부, CSV 정밀도/이스케이프.
- `tests/browser.mjs`: 실제 IndexedDB, CRUD, 가이드, Lab 오류/완료율/저장/재접속, 1/2차 측정, 확정/읽기 전용, 계산기 정수·소수·복사, CSV 다운로드, JSON 복원, 모드 변경 시 데이터 보존/계산기 비활성화, 반응형 및 인쇄.
- `tests/resilience.mjs`, `tests/persistence.mjs`: 4채널 1% 입력, 저장 용량 실패 시 초안/백업 보존, 손상 복원 거부, 실제 브라우저 종료·재실행 후 데이터·위치 보존.
- CI: Node 단위 테스트 + Chromium / Firefox / Microsoft Edge. 하위 경로 `/color-cal/`로 서버를 열어 배포 경로도 검사.
- 실제 인쇄·분광측색계의 결과는 작업자가 측정·검증해야 하며 합성 시험 데이터로 이를 대체하지 않습니다.
- 공개 GitHub Pages 설정 및 배포 완료, Firefox / Edge의 현 환경 실행은 별도 확인 대상입니다. CI 정의는 통과 결과를 뜻하지 않습니다.

## 범위 제외

패치 이미지/PDF 생성, 자동 측색계 연동, 혼합색 측정·Lab 예측·색상 일치, ICC 생성, 서버·클라우드 동기화, CSV 측정 데이터 가져오기는 구현하지 않습니다.
