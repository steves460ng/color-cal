# 잉크젯 톤 증가 시뮬레이션

이 자료는 실측이 아닌 가상 장비 실험입니다. 특정 제조사·용지의 대표값으로 해석하거나 실제 출력 보정에 사용하면 안 됩니다.

## 첨부 예시의 방향 확인

첨부 원본은 변경하지 않았습니다. 원본에서 다시 계산한 값입니다.

| 채널 | 50% 입력의 정규화 Lab 계조 (%) | 목표 50%의 제작 입력 (%) |
|---|---:|---:|
| C | 31.989 | 66 |
| M | 39.178 | 60 |
| Y | 55.412 | 44 |
| K | 23.342 | 72 |

C·M·K는 중간 계조가 약한 모델이고 Y만 강한 모델입니다. 보정 방향이 서로 다른 것은 해당 합성 원본을 역보간한 결과이며, 계산기를 임의로 반전시키지 않았습니다.

## 가정과 독립 검증 방법

- 미보정 잉크젯에서 중간 계조가 진해지는 상황을 가정합니다. 실측으로 추정한 파라미터는 아닙니다.
- 물리적 유효 면적: `A(x) = x + 4g x(1−x)[1+s(2x−1)]`, x는 0~1. g(C/M/Y/K)=0.17/0.19/0.15/0.21, s=−0.10/0.05/−0.08/−0.12. 50%에서 면적은 67/69/65/71%입니다.
- 종이 Lab=(96, 0.4, −1). 단색 100% Lab은 C=(55,−35,−45), M=(48,65,−12), Y=(88,−7,85), K=(18,0,1)로 가정합니다.
- D50 기준 Lab을 XYZ로 변환해 `XYZ = [(1−A)·XYZpaper^(1/n) + A·XYZsolid^(1/n)]^n`, n=2.2로 혼합합니다. **분광 반사율에 적용하는 Yule–Nielsen 모델의 XYZ 영역 근사**이며 실제 잉크/용지의 분광 특성을 재현하지 않습니다.
- a*, b*에 채널별 완만한 색상 곡률을 추가하고, 각 측정에 축당 최대 ±0.09 Lab의 결정론적 편차를 추가합니다. 2차에는 최대 0.2%p의 면적 드리프트도 더합니다.
- 1차: 5% 간격, 채널당 21개. 2차: 보정된 **실제 제작 입력값**을 동일한 연속 모델에 재입력합니다. 목표 계조로 2차 Lab을 만드는 방식은 사용하지 않습니다. 정수/소수 각 168패치, 합계 336패치입니다.
- 측정 모델은 앱의 보정·역보간 함수를 참조하지 않습니다. 2차 오차는 별도의 거리 수식으로 앱 표시값과 대조합니다.
- 아래 계조는 앱 기준인 종이색 대비 ΔE76/종이색–100% ΔE76 × 100입니다. 물리적 면적·농도·표준 TVI와 같은 지표가 아닙니다. 오차 단위는 %p이며 색차 ΔE나 색상 일치율이 아닙니다.

## 확인 범위와 재현

단위 테스트는 정수/소수 × 측정 간격 1/2/5/10%에서 개선 여부, 보정 방향, 범위, 실제 제작값 연결 및 JSON 왕복을 검사합니다. 세 가지 면적 증가 강도에서 모델의 단조성도 검사합니다. 이는 선택한 가정에서의 알고리즘 검증이며 실제 프린터 성능 보장이 아닙니다.

```sh
npm test
npm run simulate:inkjet
# 로컬 정적 서버가 실행 중일 때
BASE_URL=http://127.0.0.1:8050/ BROWSER_EXECUTABLE=/usr/bin/chromium npm run test:inkjet
```

앱의 JSON 복원에서 [정수 예시](../examples/inkjet-integer.json) 또는 [소수 예시](../examples/inkjet-decimal.json)를 열 수 있습니다. 새 프로젝트로 가져오므로 기존 작업을 덮어쓰지 않습니다. 예시는 1·2차 가상 측정과 확정 버전을 포함하며, 조견표 초기 간격은 2%입니다. 재실행하면 예시 JSON의 ID·시각은 새로 생성되고 측정 수치는 동일합니다. 상세 수치/CSV/인쇄 PDF/브라우저 확인 기록은 `test-results/inkjet/`에 생성합니다.
